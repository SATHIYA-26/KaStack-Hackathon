# Semantic Communication System

A prototype semantic communication system built for local, low-resource networks (slow, expensive, or unreliable connections). 

Rather than sending raw text, this system extracts key semantic components (meaning) from natural-language messages, compresses them into a short-keyed JSON packet, transmits the packet, decodes it back into text at the receiver, and validates meaning retention. All performance metrics are benchmarked and saved in an SQLite database.

## 2. Semantic Packet Design (Short Keys)

To minimize transmit sizes, the encoder maps full semantic fields to short 1-to-2 character keys:

| Full Field | Short Key | Type | Description / Example |
| :--- | :--- | :--- | :--- |
| **intent** | `i` | String | Extracted action verb (e.g., `send`, `restart`, `alert`) |
| **person** | `p` | String | Target individual or role (e.g., `officer`, `Meera`) |
| **object** | `o` | String | Entity/object acted upon (e.g., `package`, `Server B`) |
| **quantity**| `q` | Integer | Numerical counts (e.g., `5`, `3`) |
| **location**| `l` | String | Target venue/place (e.g., `Chennai`, `Gate 2`) |
| **date** | `d` | String | ISO formatted date `YYYY-MM-DD` (e.g., `2026-08-26`) |
| **time** | `t` | String | 24-hour time format `HH:MM` (e.g., `15:00`) |
| **negation**| `n` | Boolean | `true` if negation is present (e.g., "do not", "never") |
| **urgency** | `u` | Boolean | `true` if priority is high (e.g., "asap", "immediately") |
| **warning** | `w` | Boolean | `true` if safety-sensitive (e.g., "danger", "alert") |

## 3. SQLite Database Schema

The database `data/semantic_comm.db` automatically creates a `messages` table on startup containing:

*   `id` (INTEGER PRIMARY KEY AUTOINCREMENT)
*   `original_message` (TEXT): Original natural-language input string.
*   `semantic_packet` (TEXT): Compact JSON packet serialized as a string.
*   `decoded_message` (TEXT): Reconstructed message generated by the decoder.
*   `original_bytes` (INTEGER): UTF-8 byte length of the input message.
*   `packet_bytes` (INTEGER): UTF-8 byte length of the compressed JSON packet.
*   `compression_percentage` (REAL): Calculated compression efficiency.
*   `encoding_latency_ms` (REAL): Processing time of the encoder in milliseconds.
*   `decoding_latency_ms` (REAL): Processing time of the decoder in milliseconds.
*   `processing_mode` (TEXT): Processing engine mode ('normal' or 'low_resource').
*   `validation_result` (TEXT): Semantic safety check status ('safe', 'review_required', 'failed').
*   `created_at` (TIMESTAMP): Log timestamp.

## 4. API Endpoints

### Health Check
*   **`GET /`**
    *   **Response**: `{"status": "running", "service": "semantic-communication"}`

### History Log
*   **`GET /history?limit=100`**
    *   **Response**: List of logged transmissions, including packets, compression ratios, and latencies from SQLite.

### Semantic Encoding
*   **`POST /encode`**
    *   **Payload** (`EncodeRequest`):
        ```json
        {
          "message": "Send 5 packages to Chennai tomorrow at 3 PM.",
          "mode": "normal"
        }
        ```
    *   **Behavior**: Dynamically runs the spaCy encoder (if `spacy` is installed) or a robust mock fallback. Computes byte sizes, compression percentage, and execution latency, then saves the result as a new row in SQLite.
    *   **Response**:
        ```json
        {
          "semantic_packet": {
            "i": "send",
            "q": 5,
            "o": "package",
            "l": "Chennai",
            "d": "2026-08-26",
            "t": "15:00"
          },
          "benchmark": {
            "original_bytes": 45,
            "packet_bytes": 62,
            "compression_percentage": -37.77,
            "encoding_latency_ms": 0.45
          },
          "processing_mode": "normal"
        }
        ```

### Semantic Decoding
*   **`POST /decode`**
    *   **Payload** (`DecodeRequest`):
        ```json
        {
          "packet": {"i": "send", "q": 5, "o": "package", "l": "Chennai"},
          "mode": "normal"
        }
        ```
    *   **Behavior**: Uses the template decoder engine to parse fields into a grammatically clear sentence. Measures latency and automatically updates the correlated SQLite history row.
    *   **Response** (`DecodeResponse`):
        ```json
        {
          "decoded_message": "Send 5 packages to Chennai.",
          "decoding_latency_ms": 0.08,
          "mode": "normal"
        }
        ```

### Reconstruction Validation
*   **`POST /validate`**
    *   **Payload** (`ValidateRequest`):
        ```json
        {
          "original": "Send 5 packages to Chennai tomorrow at 3 PM.",
          "reconstructed": "Send 5 packages to Chennai."
        }
        ```
    *   **Behavior**: Integrates semantic matching status placeholders and logs the outcome in SQLite.
    *   **Response**:
        ```json
        {
          "status": "review_required",
          "issues": ["Validator integration pending"]
        }
        ```

## 5. Getting Started & Running Instructions

### Setup Virtual Environment & Install Dependencies
```powershell
# 1. Activate the environment
.venv\Scripts\activate

# 2. Install requirements
pip install -r requirements.txt
```

### Run the FastAPI Server
```powershell
uvicorn app.main:app --reload
```
* Once running, open the interactive Swagger UI page in your browser at: **[http://127.0.0.1:8000/docs](http://127.0.0.1:8000/docs)**.

### Run the Automated Tests
Ensure both API routes, validation rules, database inserts, and Lovkush's template decoder pass checks:
```powershell
python -m pytest
```
